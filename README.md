## Organisation und Abgabe

- **Gruppengröße:** 2 Studierende.
- **Bearbeitung:** 14 Tage pro Übung. Die Bearbeitungszeiträume können sich überschneiden.
- **Abgabefrist:** Mittwoch, 23:59 Uhr, im jeweiligen Übungszyklus.
- **Abgabeort:** Gruppenordner auf Stud.IP; pro Gruppe eine vollständige ZIP-Datei.
- **Dateiname:** `grX_abgY_SWEng2.zip` (X = Gruppennummer, Y = Übungsnummer).

Das vorgegebene Namensschema ist wichtig: Laut Übungsinformationen werden falsch benannte Abgaben mit 0 Punkten bewertet. Die Übungen sind außerdem Voraussetzung für die Prüfungszulassung; die genauen Bedingungen stehen in der Modulordnung.

Weitere Details stehen in den [allgemeinen Übungsinformationen](AblageDateinINFO/00_%C3%9Cbungen_Informationen.pdf). Die Abgabe selbst erfolgt über **Stud.IP**, nicht über GitHub.
